# The Museum of Me（仿作）v4 — 依原作量測的鏡頭軌跡與展廳配置

日期：2026-09-28
狀態：待審閱
取代：v3 規格的 §1（原作結構）、§4（展廳帶的轉場與房間配置）、§5（鏡頭）、§9 的一鏡到底測試，以及 v3 中 Likes／Videos 兩房與 Words 推近的做法。其餘沿用 v3：時間軸的分段 id 與組合規則（§3）、地毯 → 馬賽克 → 網絡（§6）、畫面質感（§7），以及 v2 的照片管線、表單、配樂、匯出與錯誤處理。

依據：再次逐格分析原作影片（`Intel Museum of Me_720p.mp4`，1152×720、30 fps），並加入兩種量測。以下秒數都指原作影片的時間。

- **標示牌當尺**：每個房間的標示牌（圖示＋名稱＋編號）實體大小相同。名稱字寬（依字形寬度換算）的比值就是鏡頭到該面牆的距離比。
- **光流**：以 ORB 特徵比對相鄰影格（每秒 10 組），估計相似變換，得到每秒的水平位移（px/s）、縮放比（> 1 表示接近）與旋轉。量測腳本放進專案（§8），也用來驗收我們的輸出。

距離的絕對值以「Friends 牆在 29 s 時距鏡頭 7 m」為基準，焦距取 1045 px／720 px 畫面高（等於我們 38° 垂直視角的渲染）。在此基準下，Friends 前的參觀者約 1.8 m 高，與實際相符。

- 全片只有三次擦過轉場：說明文字後的內轉角與白色厚隔牆（24–26 s，隔牆側面有一欄小字）、Photos → Location（53–55 s）、Videos → 機器手臂房（121–125 s）。
- Friends 與 Photos 在同一面牆上，中間沒有隔牆（37 s 時 Photos 2 的標示牌直接出現在同一面牆上）。
- Location → Words、Words → 大廳之間都沒有隔柱。

## 2. 目標

依 §1 重建 0–150 s 的鏡頭與空間。成功標準：
- 以 §8 的光流腳本量測我們的輸出，每一列（§1 表格）的水平速度與縮放趨勢方向相同，累計縮放比與原作相差不超過 25%。
- 以相同比例的時間點每 2 s 並排截圖比對，房間、物件、構圖都能對應。
- 只有 §1 列出的三次擦過轉場；其餘房間交界沒有隔柱。
- 其餘標準沿用 v3：展名在指定時刻完全位於正中並與牆面平行；從開場到網絡之間沒有剪接或整畫面的淡出。

不做的事：與 v3 相同（不放 Intel、Core、Facebook 的商標與品牌畫面，也不內建 Nijiko）。

## 3. 時間軸

沿用 v3 的分段 id、基準時長與組合規則。以下是各段內的時間點（段內比例 u）：

| id | 原作 | 段內時間點 |
|---|---|---|
| `title` | 0–5 | 標題在 0.3 位於注視點 |
| `exhibition` | 5–15 | 偏航在 0.2 歸零；展名在 0.55 位於正中 |
| `intro` | 15–22 | 說明文字在 0.5；段尾是內轉角 |
| `portraits` | 22–38 | 0–0.25 白色厚隔牆擦過；0.56 起開始拉遠 |
| `photos` | 38–53 | 持續拉遠並升高，1.0 時達到最遠 |
| `moments` | 53–63 | 0–0.2 深色隔柱擦過；之後橫移並靠近 |
| `words` | 63–92 | 0.1 起直線走近；LED 內容在 0.41、0.57、0.79 切換（§5） |
| `likes` | 92–106 | 0–0.1 向右轉約 30°、離開 LED 牆；之後是大廳繞行的前半 |
| `videos` | 106–122 | 0–0.4 繞行的後半；0.4–0.95 沿 Videos 牆橫移；0.95 起隔柱擦過 |
| `robots` | 122–150 | 0–0.1 隔柱擦過；之後直線朝平台前進 |

- 固定長度組合中缺少某段時，鏡頭關鍵點依出現的段落銜接：
  - 缺 `portraits`：`photos` 從距離 7 m 開始拉遠。
  - 缺 `likes`、`videos`（60 s）：`words` 的右轉接到機器手臂房前的隔柱。
  - 有 `likes`、缺 `videos`（90 s）：繞行在 `likes` 段內完成，最後 10% 接隔柱。
- 馬賽克之後沿用 v3。

## 4. 空間配置（`stage/strip.ts`，純資料）

v3 的「所有房間沿 +x 排成一列」改為由鏡頭軌跡決定的平面配置。房間的牆位置由鏡頭在該段的位置與 §1 量得的距離推算，所以一律先算鏡頭軌跡（§6），再擺放牆與物件。

標記「（估）」的數值沒有直接量得，是由畫面估計，實作時以 §8 的並排比對與 motion 比較校正；其餘數值來自 §1 的量測。

- **白牆區（title → photos）**：一面連續的背牆，z = 0。
  - 內轉角位於 intro 段尾，接白色厚隔牆（厚 1.2 m、深 4.5 m，估），其朝向鏡頭的側面貼一欄小字（原作 26 s）。
  - 隔牆之後的 Friends 與 Photos 共用同一面背牆，中間沒有隔牆。
  - 背牆高度需容納拉遠後的整面照片堆疊（原作 52 s 的畫面上緣）：牆高 7 m（估）。
  - Friends：方形畫布一列，中心高 1.9 m，間距依原作（約 1.9 m）。
  - Photos：斜向往右上堆疊。依原作 52 s，堆疊高度 1.2–6.2 m，右端最高。
  - Photos 盡頭是白牆的側面，接著是深色隔柱（原作 51–55 s）。
- **Location**：暗房，背牆比 Photos 背牆往鏡頭方向凸出 5 m（淺房）。
  - 燈箱 1.5 × 2.5 m，下緣 0.4 m，間距 2.6 m，共三座：LATITUDE、LONGITUDE、LOCATION。文字沿用 v2。
  - 右側同一面暗牆上是 Words 4 的標示牌，牆面沒有中斷。
- **Words**：Location 牆的右側開一個凹室，LED 牆位於凹室底。
  - LED 牆寬 10 m、高 3.6 m（估）。凹室深度讓 LED 牆在 words 段 0.1 時距鏡頭約 14 m；走近到段尾時約 3.7 m（×3.75）。
- **大廳**：一個暗色大廳，讚手勢雕塑（沿用 v2 模型，含圓台）位於中央。
  - 鏡頭進入時正前方是 Likes 牆：一列古早映像管電視（箱型機身＋支架，機身約 0.5 m 寬），標示牌 Likes 5.1 在右端。
  - 逆時針方向依序是 Photos 5.2 的網格照片牆（6 × 5 格），以及與它成直角的 Videos 5.3 牆（約 7.7 × 3.6 m，整面顯示一張照片跨越所有面板）。
  - Videos 牆右側是一面垂直的側牆，上面是小螢幕陣列（原作 116–121 s）。
  - 網格照片牆：每隔 1.2–2 s（估），隨機一至兩格換成另一張照片（以 t 決定，可重現）。
- **機器手臂房**：白色大房，平台與手臂沿用 v3，平台位於鏡頭前進方向的正前方。
- **擦過轉場的位置**：只有 §1 的三處。每一處的隔柱都位於鏡頭軌跡與後方牆面之間、距鏡頭約 1.6 m，讓它擦滿畫面並失焦。

## 5. LED 字牆（`words` 段）

- **跑馬燈**：每一行各自橫向捲動，**相鄰兩行方向相反**，速度相同（每秒約 1.5 個字寬，估）。
- **內容切換**：以下都是螢幕本身的內容改變，不是鏡頭推近。
  - u < 0.41：小字，約 14 行。
  - 0.41–0.55：字放大，約 8 行。
  - 0.55–0.57：其中一個詞（使用者第一個關鍵字）原地放大成高亮框（原作 79 s 的 COM）。
  - 0.57–0.79：該詞重複填滿整面，約 4 行（原作 80–85 s）。
  - 0.79–1.0：回到小字，約 14 行。
- 切換瞬間完成（原作如此）。一鏡到底的亮度檢查排除這三個切換點前後 0.3 s。

## 6. 鏡頭（`camera/path.ts`）

- 0–150 s 改為一條連續的關鍵點路徑。位置與注視點各一條 Hermite 曲線，關鍵點依 §1 的量測放在各段的比例時間上。
- **白牆等速段（exhibition 0.5 → portraits 0.56）**：x 方向仍然嚴格等速，速度 V。
  - V 的基準改為 0.95 m/s（v3 的 1.1 m/s 比原作快約 17%）。
  - 固定長度仍然 `V = max(基準, 所需)`。
- **視角**：垂直 FOV 38°，全片固定。
- **景深焦點**：依鏡頭到注視點的距離，平滑變化，不得在任何一幀跳動（修正 v3 審查 I2）。機器手臂房的焦點放在平台上。
- **連續性**：從 0 到 ending 之前，位置、速度、FOV、焦點都必須連續。dive 起點接在機器手臂房的前進方向上，不再有反向的 x 速度（修正 v3 審查 I4）。

## 7. 一併修正的 v3 審查項目

- **I1**：網絡連線的材質 `depthWrite: false`，不再在地毯上切出暗線。
- **I3**：bloom 在 dive → mosaic → network 之間平滑過渡；AO 強度改為隨 bloom 連續變化，不再以門檻切換。
- **M1**：中心球體的 24 條連線改為連到最近的 24 個節點。
- **M2**：星點出現後（network 0.4 起），鏡頭與任何星點保持 1.5 m 以上的距離。

## 8. 測試與量測

- **量測工具**：`scripts/measure-motion.py <video> <out.csv>`，用 OpenCV ORB，每秒輸出水平位移、縮放與旋轉。
  - `npm run motion`：對原作與我們匯出的影片（自動模式、同一組照片）各跑一次，依 §1 表格的每一列比較，列出差異。
- **單元測試**：
  - strip：只有三處擦過轉場；Friends 與 Photos 之間沒有隔牆；物件落在所屬區域內；白牆文字不重疊。
  - path：
    - 白牆等速段每幀 x 位移相同；
    - 位置、速度、FOV、焦點在 0 到 ending 之間連續（每幀變化有上限）；
    - dive 中 x 速度不為負；
    - 繞行段中鏡頭到雕塑的距離在 5.5–9 m 之間，視線累計左轉 80–100°；
    - 機器手臂房中鏡頭的 x 速度接近 0。
  - LED：相鄰兩行的捲動方向相反；各時間點的行數與 §5 相符。
  - 網格照片牆：換圖由 t 決定（同一個 t 結果相同，t 倒退也一樣）。
- **e2e**：
  - 各段中位亮度沿用 v3。
  - 一鏡到底：比較相鄰 0.5 s 畫面的平均亮度（v3 已改用平均值，本版正式寫入規格），差 < 60。只排除三次擦過轉場與 LED 的三個切換點。
- **目視驗收**：`npm run compare` 改為每 2 s 一組（0–150 s 共 75 組），並另外輸出 motion 比較表。
