# The Museum of Me（仿作）v3 — 一鏡到底規格

日期：2026-09-28
狀態：待審閱
取代：v2 規格的 §3（分鏡）、§3.1（白牆運鏡）、§3.2（時長）、§4 的調色與白房材質，以及 §5 中 `stage/layout`、`stage/sets`、`camera/shots`、`render/transitions`、`render/stage-renderer` 的組合方式。其餘部分沿用 v2：Worker 照片管線、表單、配樂風格、匯出、錯誤處理、各房間的物件本身（燈箱、LED、雕塑、影像牆、手臂、網絡）。

依據：逐格分析原作影片（`Intel Museum of Me_720p.mp4`，1152×720、30 fps、225 s）。以下引用的秒數都指原作影片的時間。

## 1. 原作的結構（量測結果）

- **0–150 s 是單一鏡頭**：鏡頭沿著一整排並排的房間等速向右橫移，速度約為每秒畫面寬度的 13%，全程沒有剪接、淡出或停頓。
- **開場角度**：0 s 時鏡頭朝右斜看牆面（牆與地板的交線往右上升），角度約 15–20°；約 7 s 已與牆面平行；10.5 s 時展名「TIM SPARKE EXHIBITION」與時間戳位於畫面正中。
- **白牆的順序**：標題「The Museum of Me」＋副標 → 展名＋時間戳 → 大頭照＋「This exhibition is a journey of visualization that explores who I am.」（18.5 s 位於正中）→ 牆的內轉角（21 s）。
- **房間之間的轉場**：每個房間的盡頭先出現一面垂直於背牆的側牆（白房是白色、暗房是深灰），接著一根深色隔柱從鏡頭前掠過並擦滿畫面（近處失焦），下一個房間隨之出現。例如 22–24 s、53–55 s、122–125 s。
- **各房間出現的時間**：Friends 24–38 → Photos 38–53（44 s 有一位參觀者貼著鏡頭經過）→ Location 55–63 → Words 63–92 → Likes 92–106 → Videos 106–122 → 機器手臂 125–150。
  - Words：66–70 s 可看到整面 LED 牆；72–90 s 一邊橫移一邊推近；78–84 s 牆面換成 COM 滿版。
- **150–200 s 是連續的收尾**：鏡頭下降、擦過手臂、低空掠過照片地毯（150–162）→ 周圍漸暗成黑色，只剩地毯；地毯浮起、傾斜旋轉，逐漸顯出肖像並縮小（162–174）→ 肖像變成網絡中心的球體，節點與連線長出，鏡頭拉遠成星座球體（174–198）。
- **畫面質感**：文字是實心深黑；白牆是淺灰，四周暗角明顯；地面是灰色水泥；暗房是深灰而不是純黑；整體輕微去飽和，有細顆粒；近處物件失焦。

## 2. 目標

依 §1 重建一鏡到底的影片。成功標準：
- 把輸出影片與原作逐段並排，以相同比例的時間點對照，每段的房間、物件與構圖都能對應。
- 白牆段 x 方向等速（每一幀的位移相同）。
- 展名在指定時刻完全位於正中並與牆面平行。
- 從開場到網絡之間，沒有任何剪接或整畫面的淡出。

不做的事：與 v2 相同（不放 Intel、Core、Facebook 的商標與品牌畫面，也不內建 Nijiko）。原作 200 s 之後的品牌片尾，改為我們自己的白卡片尾。

## 3. 時間軸（`plan/storyboard.ts` 改版）

分段 id 與自動模式的基準時長（秒，取自原作）：

| id | 基準 | 內容與時間點（相對段起點的比例） |
|---|---|---|
| `title` | 5 | 標題在 0.3 位於注視點 |
| `exhibition` | 10 | 展名在 0.55 位於正中並平行（原作 10.5 s） |
| `intro` | 7 | 說明文字在 0.5 位於正中；段尾是內轉角＋隔柱 |
| `portraits` | 16 | Friends 標示牌＋方形畫布一列＋參觀者 |
| `photos` | `clamp(9 + 0.3·N, 12, 24)` | 斜向堆疊＋參觀者（其中一位貼近鏡頭） |
| `moments` | 10 | 暗房燈箱 |
| `words` | 29 | 牆在 0.2 完整入鏡；0.3–0.95 推近；0.52–0.72 為高亮字滿版 |
| `likes` | 14 | 讚手勢雕塑（靠近鏡頭）＋背牆螢幕＋側牆螢幕陣列 |
| `videos` | 16 | 影像牆＋側牆螢幕陣列 |
| `robots` | 28 | 白色大房、手臂與平台；後 0.1 開始往平台靠近 |
| `dive` | 12 | 擦過手臂、低空掠過地毯，最後升到地毯上方並漸暗 |
| `mosaic` | 12 | 地毯浮起、傾斜、染色成肖像、縮小，淡入清晰的主視覺 |
| `network` | 24 | 主視覺變成中心球體，網絡長出，鏡頭拉遠 |
| `ending` | 8 | 淡入白卡片尾 |

- 自動模式：各段使用基準時長（N = 20 時約 206 s，N ≥ 50 時約 215 s）。
- 固定長度：先依長度選組合，再把各段基準時長等比例縮放到剛好等於選定長度。
  - 30 s：`title, exhibition, photos, robots, dive, mosaic, ending`
  - 60 s：再加入 `intro, portraits, words, network`
  - 90 s：再加入 `moments, likes`
  - 120 s：全部
  - 地毯就是馬賽克，所以 `robots`、`dive`、`mosaic` 永遠同時出現。
- 配合音樂長度：同 v2（30–300 s，門檻 < 45 / < 75 / < 105）。

## 4. 展廳帶（`stage/strip.ts`，純資料）

- **座標**：所有房間在同一個 `THREE.Scene` 中沿 +x 排列。背牆在 z = 0（面向 +z），鏡頭行進線在 z = D = 7、眼高 1.6。
- **房間的 x 範圍**：由時間決定，`x = V·t`。從 `title` 到 `robots`，每個出現的段落各佔一段 `[V·start, V·end]`；`dive` 之後鏡頭離開行進線，不再用這個規則。
- **轉場結構**：相鄰房間的交界放三個東西：
  - 前一房的側牆：在 z 0–4.5，面向 −x，顏色依房間，白房淺灰、暗房深灰；
  - 0.6 m 厚的隔牆；
  - 一根前景隔柱：寬 1.1 m、全高，位於 z = 5.4，顏色取較暗的那一側。
  鏡頭經過時，隔柱會擦滿畫面。白牆與 Friends 之間的交界另外做成內轉角：背牆接一面垂直的白牆。
- **房間深度**：
  - 一般房間背牆在 z = 0。
  - Words 背牆後退到 z = −5（原作 66–70 s 可以看到整面 LED 牆與周圍的暗處）。
  - 機器手臂房背牆在 z = −10，平台中心在 (房中央, z = −2)。
- **速度**：`V = max(1.1, 所需)`。1.1 m/s 在 D = 7、全幅垂直 FOV 38° 時，約等於每秒畫面寬度的 13%。「所需」與 v2 相同，確保標題、展名、說明文字在牆上不重疊。
- **白牆元素**：
  - 標題中心位於 `title` 段 0.3 時刻的注視點右側 0.4 m。
  - 展名中心 = `V · t_ex`，其中 `t_ex` 為 exhibition 段 0.55 的時刻。
  - 說明文字位於 intro 段 0.5 時刻的鏡頭 x，但不得與展名重疊，否則往右推。
- **房內物件**：沿用 v2 的物件，只改為依房間的 x 範圍擺放。
  - Friends：畫布一列，平均分布在房間中段 80%。
  - Photos：斜向堆疊分布在整個房間。
  - Location：燈箱每 3 m 一座。
  - Words：LED 牆寬度 = 房長 − 4 m。
  - Likes：雕塑位於房中央的 z = 3.2，背牆有一列小螢幕，左側牆是螢幕陣列。
  - Videos：影像牆在背牆中央，右側牆是螢幕陣列。
  - 機器手臂房：手臂與平台，以及漂浮的照片。
- **房間標示牌**：原作的標示牌是圖示＋名稱＋小字說明＋編號，白房是深色字、暗房是白色字，位於每個房間起點後 1.5 m、高 1.5 m。

## 5. 鏡頭（`camera/path.ts`，取代 `camera/shots.ts`）

- **title 到 robots（行進段）**：`x(t) = V·t`，y = 1.6，z = 7。
  - 偏航角：`yaw(t) = 18° · (1 − smoothstep(0, t_par, t))`，其中 `t_par` = exhibition 段 0.2 的時刻（原作約 7 s）。在 `t_ex` 之前已經為 0。
  - 注視點：`(x + 10·sin yaw, 1.85, 7 − 10·cos yaw)`。
- **Words 推近**：x 仍然是 `V·t`（橫向等速不變），只有 z 在 0.3–0.95 間以 smoothstep 從 7 推到 1.5；注視點隨之保持正對背牆。
- **dive**：從行進線上的位置出發，以 Hermite 關鍵影格前進：
  - 往平台靠近，擦過最近的一支手臂（距離 0.6 m，會失焦）；
  - 降到地毯上方 0.9 m 往前滑；
  - 最後升到地毯中心上方 4 m 往下看。
  - 起點的位置與速度都和行進段相接，不會有跳動。
- **mosaic 與 network**：鏡頭從地毯上方沿連續的 Hermite 路徑拉遠。地毯與網絡本身的動畫見 §6。
- **ending**：固定鏡頭，白卡位於鏡頭前方。
- **連續性**：整條路徑的位置與速度都必須連續，從 0 到 ending 之前都不能有跳點。

## 6. 地毯 → 馬賽克 → 網絡（同一個場景）

- **地毯**：平台上鋪 64 × 36 格照片小方塊，每格的照片取自馬賽克指派（`assignMosaic`），所以它從一開始就是馬賽克，只是還沒上色。
- **漸暗（dive 段後 40%）**：用一個包住鏡頭與平台的黑色球殼，不透明度 0 → 1，並以 renderOrder 蓋掉地毯以外的所有物件。地毯的材質在它之後繪製，因此會留下來。
- **mosaic 段**：
  - 地毯群組離開平台，傾斜約 25° 並緩慢旋轉，面向鏡頭。
  - 每格的顏色從 1 漸變到肖像的著色值（v2 的 tint）。
  - 後 45% 整片縮小到 0.3，同時淡入清晰的主視覺照片。
- **network 段**：
  - 主視覺照片在前 10% 收縮成中心球體（同一位置，交叉淡入）。
  - 照片節點依距離由近到遠依序長出（縮放 0 → 1），連線隨之淡入。
  - 星點與藍色連線在 0.4 之後出現，鏡頭拉遠到能看見整顆星座球體。
  - 最後 15% 整體淡出成黑色。
- **ending**：黑色中淡入白卡（v2 的卡片內容）與副標。

## 7. 畫面質感

- **調色（修正 v2 審查的 Important #1）**：
  - GradeEffect 先把線性色轉成 sRGB，在 sRGB 中套用飽和度 0.88、黑位抬高 0.012，以及依亮度加權的顆粒（暗部較少），再轉回線性。
  - 黑邊維持 2.35:1。
  - 純黑背景的中位亮度必須低於 20/255。
- **文字**：牆上所有文字改為 `#141414`。Neutral tone mapping 會保留接近黑色的值，加上 §7 的 sRGB 調色，文字會維持實心深黑。
- **白房**：
  - 牆面 `#d9d8d4`，暗角由 VignetteEffect 提供（offset 0.3、darkness 0.55）。
  - 地面使用程式生成的水泥貼圖（灰 `#a49f97` 加細斑點），粗糙度 0.7。
- **暗房**：牆面 `#161616`、地面 `#101010`，保持深灰。燈箱、LED、螢幕發光，暗房範圍內 bloom 較強。bloom 強度依鏡頭 x 位於哪個房間，在交界處平滑過渡。
- **景深**：使用 DepthOfFieldEffect，焦點放在鏡頭到背牆的距離，只有近處的隔柱、貼近鏡頭的參觀者和手臂會失焦。
- **參觀者**：沿用 v2 的人形，白房是灰衣、暗房是剪影。Photos 房另外放一位站在 z = 5.9 的參觀者；因為離鏡頭很近，視差會讓他像是貼著鏡頭快速經過（原作 44 s）。

## 8. 同時修正的 v2 審查項目

- **Important #2 配樂合成太慢**：
  - 改為分段合成：每 16 s 一段，只放該段開始的音符，各段自己長度加上殘響尾巴，再以 overlap-add 疊加。
  - 母帶的淡入淡出與限幅改在 JS 中對最終緩衝處理。
  - 合成與照片處理並行開始。
  - 目標：137 s 的配樂在 5 s 內完成。
- **Important #3 背景分頁降速**：匯出迴圈改用 `MessageChannel` 讓出執行緒，不再使用 `setTimeout`。

## 9. 測試

- **單元測試**：
  - storyboard：各模式的組合與總長，30 s 版本一定包含 robots、dive、mosaic。
  - strip：房間 x 範圍連續、交界結構齊全、物件落在所屬房間內、白牆文字不重疊。
  - path：
    - 行進段每幀 x 位移相同（誤差小於 1e-9）；
    - 偏航角在 `t_par` 之後為 0，展名在 `t_ex` 時位於正中；
    - Words 推近時 x 仍等速；
    - 整條路徑位置連續、速度連續（dive 起點）。
  - 馬賽克與地毯使用同一組指派；網絡節點依距離排序長出。
  - 分段合成的音符分配與 overlap-add 長度正確（純函式部分）。
- **e2e**：
  - 預覽亮度：各房間的中位亮度、純黑背景低於 20/255、2.35:1 黑邊。
  - 一鏡到底：取 0 到 network 結束之間每 0.5 s 的畫面，相鄰兩格之間不得出現整畫面的亮度突變（中位亮度差 < 60），但隔柱經過的時段除外，這些時段由 strip 提供。
  - 匯出 MP4 驗證沿用。
  - 137 s 自動模式的合成時間低於 5 s。
- **目視驗收**：用同一個腳本，在原作影片與輸出影片上，於相同比例的時間點各擷取 12 格並排比對。
